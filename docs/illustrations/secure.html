Stock OS

  • Launcher and app store show ads
  • Vendor updaters can flash the old firmware back
  • Factory test tools left running
  • No newer firmware since the 2024 build

LumenOS

  • No ads on the home screen; ad and tracker domains blocked in every app*
  • Vendor updaters and test tools removed (HY300)
  • API keys never inside the app: a private key service holds them
  • Nothing flashed: LumenOS Undo restores the stock setup
* System-wide blocking uses AdGuard DNS, switched on by the 5-second unlock or the full install. Honest limit: Android's security patch level is set by the projector maker's firmware. Lumen can't raise it; it removes risky extras and blocks bad domains instead.
